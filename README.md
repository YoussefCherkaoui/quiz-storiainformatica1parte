# Quiz di Storia dell'informatica

Quiz per preparare la prima parte dell'esame di Storia dell'informatica all'Università di Torino.

**Prova online:** https://youssefcherkaoui.github.io/quiz-storiainformatica1parte/

![Quiz di Storia dell'informatica](https://raw.githubusercontent.com/YoussefCherkaoui/portfolio/main/img/quiz-storiainformatica1parte.jpg)

## Come funziona

- Le domande vengono mescolate a ogni partita
- Domande a scelta multipla e a menu a tendina
- Punteggio come all'esame: +2 per ogni risposta giusta, -1 per ogni risposta sbagliata

## Tecnologie

Un solo file `index.html` con HTML, CSS e JavaScript, senza dipendenze.
